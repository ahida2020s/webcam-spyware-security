## webcam-spyware-security
The Webcam Spyware Security System is developed to address growing concerns around webcam hacking and digital surveillance. It allows users to control webcam access at the system level, ensuring that no malicious application can access the camera without proper authorization.




## 🚀 Features
- Enable/Disable webcam (system-level)
- Email-based authentication
- Face recognition login
- Intruder detection with video recording
- Email alerts
- Privacy scheduling
- Security logs
